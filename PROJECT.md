# Stitch Custom Android IPTV Player

## Description
A remote-friendly (D-Pad arrow key navigation) custom Android IPTV player app designed using Stitch UI design systems (Slate/Dark design, Netflix-red theme).

## Tech Stack
- HTML5 / CSS3 / Tailwind CSS (via CDN)
- Vanilla JS (no dependencies, optimized for TV WebViews)
- `hls.js` for HLS playback
